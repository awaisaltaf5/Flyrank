# Prompts Used During Development

## Prompt 1 – Project Setup

> Create a React project using Vite inside the Week3 folder. Use JavaScript (not TypeScript). Organize the project using a professional folder structure with `src/components/`, `src/pages/`, `src/hooks/`, `src/utils/`, `src/assets/`, and `src/styles/`. Install all required dependencies.

## Prompt 2 – Build the Application

> Build a responsive Profile Settings Dashboard with the following requirements:
> - Username and Email inputs
> - Theme selector
> - Notification toggle
> - Save button
> - Form validation
> - Success message
> - Responsive design
> - Clean UI
> - Store settings in Local Storage
> - Accessibility: labels connected with inputs, keyboard navigation, aria-invalid where necessary
> - Use React functional components and reusable components where appropriate.

## Prompt 3 – Code Review

> Review the entire project as a senior frontend engineer. Check:
> - React best practices
> - Accessibility
> - Performance
> - Component structure
> - State management
> - Validation
> - Code duplication
> - Folder organization
> Suggest improvements before I commit the code.

## Prompt 4 – Refactoring

> Refactor the code using the previous review. Keep functionality exactly the same. Only improve:
> - readability
> - maintainability
> - reusability
> Explain every change.

## Prompt 5 – Documentation

> Write professional documentation for the project including:
> - README with setup instructions, project structure, and code review notes
> - File explanations
> - Dependency explanations
> - Accessibility notes
> - Code review summary
> - Refactoring opportunities
> - Suggested unit tests
