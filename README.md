# FlyRank AI — Frontend Engineering Internship

A structured learning repository for the **FlyRank AI Frontend Engineering Internship**. This repository documents weekly assignments, projects, exercises, and progress throughout the internship program.

---

## Repository Overview

This repository serves as a central hub for all frontend engineering work completed during the FlyRank AI internship. Work is organized chronologically by week, making it easy to track learning progression, review past assignments, and showcase completed projects.

Each week folder contains self-contained work including:

- **Assignments** — Guided exercises and tasks
- **Projects** — Hands-on applications of weekly concepts
- **Notes** — Key learnings, references, and documentation
- **Resources** — Links, readings, and supplementary materials

---

## Goals

- Build a strong foundation in modern frontend development practices
- Gain practical experience with industry-standard tools and frameworks
- Develop production-ready UI components and web applications
- Learn to collaborate effectively using Git and GitHub workflows
- Create a portfolio of work that demonstrates frontend engineering skills
- Understand how frontend systems integrate with backend APIs and AI-powered features

## Learning Objectives

### Week-by-Week Progression

| Phase | Focus Areas |
|-------|-------------|
| **Foundation** | HTML, CSS, JavaScript fundamentals, Git basics, development environment setup |
| **Core Frontend** | React components, props, state, hooks, event handling, conditional rendering |
| **Styling & UX** | Responsive design, CSS layouts, Tailwind CSS, accessibility basics |
| **Application Architecture** | Component composition, routing, state management, API integration |
| **Advanced Topics** | Performance optimization, testing, TypeScript, deployment |
| **Capstone** | End-to-end project integrating frontend with AI-powered features |

### Key Skills to Develop

- **Component Design** — Build reusable, maintainable UI components
- **State Management** — Manage application state effectively across components
- **API Integration** — Fetch and display data from REST APIs
- **Responsive Design** — Create layouts that work across devices and screen sizes
- **Code Quality** — Write clean, readable, and well-documented code
- **Collaboration** — Use Git branching, pull requests, and code review practices
- **Problem Solving** — Debug issues systematically and research solutions independently

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/awaisaltaf5/Flyrank.git
   cd Flyrank
   ```

2. **Navigate to the current week's folder**
   ```bash
   cd week-01
   ```

3. **Install dependencies** (when a project includes a `package.json`)
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
